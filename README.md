# 基金雷达（FundRadar）

每个交易日 **14:30** 自动盯盘：抓取大盘指数、持仓基金净值/盘中估值、纳指与汇率，按你的持仓比例计算趋势评分和「加仓 / 持有 / 减仓 / 观望」建议，并通过企业微信、QQ 邮箱和 DSH 会话提醒推送。

配套一个本地管理面板：可以 **添加/删除基金**、**修改持有份额和收益**，收益每天自动更新，并给出组合层面的**配置诊断**。

> 纯 Python 标准库实现，无需安装第三方包；数据与密钥只保存在本机，面板只监听 `127.0.0.1`。

## 快速开始

```powershell
cd "D:\我的文档\deepseek-harness\default-workspace\fund-radar"

# 1. 配置基金、企业微信 webhook、QQ 邮箱授权码（密钥输入不回显）
D:\python\python.exe configure.py
# 如果只差 QQ 授权码，可以用这个更短的向导：
# D:\python\python.exe set_email_auth.py

# 2. 测试推送（企业微信 / 邮件）
D:\python\python.exe run.py --test-push

# 3. 立即跑一次，生成报告
D:\python\python.exe run.py --once

# 4. 注册 14:30 推送任务和 20:30 静默刷新任务
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_task.ps1

# 5. 打开管理面板（或双击 start_dashboard.bat）
D:\python\python.exe dashboard.py --port 8765
```

管理面板地址：**http://127.0.0.1:8765**

## 管理面板（按钮操作）

- **添加基金**：右上角「+ 添加基金」，输入 6 位代码，名称/类型/最新净值会自动查询；也可手动填写。
- **修改持仓**：每张基金卡片上的「修改持仓」，可改份额、成本价、加仓预算、目标占比。
- **删除基金**：卡片上的「删除」，只删除本地记录，不会赎回基金。
- **两种录入方式**：
  - 按「份额 + 成本价」：收益 = 份额 ×（最新净值 − 成本价），每天自动更新。
  - 按「当前市值 + 累计收益」：系统按最新净值反推份额和成本价，之后同样自动更新。
- **刷新行情**：立即抓取最新净值/估值并重算收益和建议；不发送推送。
- **自动刷新**：页面每 60 秒同步一次；每天 14:30 / 20:30 计划任务更新后会自动反映。
- **按比例给建议**：每只基金有「目标占比」，超过单只上限（默认 65%）会提示减仓；低于目标会提示再平衡；买入金额会受目标占比约束。

面板不会随系统自启；双击 `start_dashboard.bat` 打开，或运行
`D:\python\python.exe dashboard.py --port 8765`。部分安全软件会拦截开机启动项，因此安装脚本不自动注册自启。

## 配置诊断（组合层面）

面板顶部和每日报告里新增「配置诊断」，从 6 个维度给组合打分（0–100）：

- **集中度**：最大单只占比、HHI；
- **目标一致性**：实际占比与目标占比的偏离；
- **资产类别**：权益 / 混合 / 债券 / 货币 / 黄金的分散度；
- **区域/币种**：A 股、美股、海外资产比例；
- **风格重叠**：科技成长等同类风格暴露；
- **防守资产**：货币/债券缓冲是否足够。

诊断会自动识别这些问题：

- 目标占比合计不是 100%（系统会按比例归一化，并在面板提供「目标占比均分」一键修正）；
- 同一只基金同时持有 A/C 份额（重复暴露）；
- 基金数量超过 8 只、单只亏损超过 15%、科技/权益过度集中、缺少防守资产等。

诊断结果会写进 HTML/Markdown 报告，并随邮件发送；面板顶部实时显示分数、维度条、问题清单和配置建议。诊断只针对“结构是否合理”，不替代每日趋势信号，也不构成投资建议。

### 建议目标占比

在诊断面板点「查看建议目标」，系统会按“均衡型”模型生成一版目标：

- 科技成长 40%、红利/价值 10%、防守（债/货币）20%、黄金 8%、海外新兴 10%、均衡/其他 12%；
- 同类基金内部按你当前的持仓比例分配，尽量不改变你的风格偏好；
- 同一基金 A/C 份额只保留较大的一份，另一份目标设为 0，提示合并；
- 仓位低于 1.5% 的基金建议清仓/并入同类，目标设为 0；
- 单只上限沿用 `portfolio.max_single_weight`（默认 65%）。

点「应用建议」后，目标占比会写入 `config.json`，之后每日建议会正式按目标占比做再平衡。模型比例可在 `config.json` 的 `portfolio.target_model` 里修改。

## 每天的运行方式

| 时间 | 动作 |
|---|---|
| 14:30 | Windows 计划任务 `FundRadar_1430` 运行 `run.py --scheduled`：抓取、计算、写报告、发企业微信/邮件 |
| 14:33 | DSH 会话提醒读取 `reports/latest.md`；报告缺失或过期会现场补跑，休市则只回复「今天休市」 |
| 20:30 | 计划任务 `FundRadar_2030` 静默刷新一次，把当日实际净值写进报告和收益，**不推送** |
| 全天 | 管理面板打开时每 60 秒刷新一次收益和占比 |

- 计划任务只需要当前用户权限，不依赖 DSH 是否打开。
- DSH 提醒依赖 DSH 处于运行状态；两条通道互为备份。
- 休市日（周末/节假日）自动跳过，不推送。
- 20:30 的刷新只更新报告、数据库和面板收益，不会重复发企业微信/邮件。
- 基金 15:00 前下单按当日净值确认；QDII（016452）按当晚美股收盘净值确认，14:30 的估算已把纳指期货与汇率纳入。

## 配置说明（config.json）

```json
{
  "funds": [
    {"code": "000001", "name": "示例宽基基金A",
     "cost": 1.0, "shares": 1000,
     "kind": "a_share", "benchmark": "sh000300",
     "add_budget": 200, "target_weight": 0.6}
  ],
  "portfolio": {"max_single_weight": 0.65, "rebalance_band": 0.05},
  "push": {
    "wecom": {"enabled": true, "webhook": "https://qyapi.weixin.qq.com/..."},
    "email": {"enabled": true, "smtp_host": "smtp.qq.com", "smtp_port": 465,
              "user": "you@qq.com", "password": "SMTP授权码", "to": "you@qq.com"}
  }
}
```

- `shares`：持有份额（面板会自动写入）。`cost`：每份成本价。
- `amount` / `amount_mode`：兼容旧数据；有 `shares` 时以份额为准。
- `target_weight`：目标占比（0~1）；不填则按基金数量平均分配。
- `portfolio.max_single_weight`：单只基金占比上限，默认 0.65。
- `portfolio.rebalance_band`：目标占比的容忍带，默认 ±5%，避免频繁调仓。
- `add_budget`：单次加仓预算上限，还会受 `risk.max_add_pct`（默认 20% 持仓市值）约束。
- 密钥只写入本地 `config.json`，不会出现在报告、日志或对话中。

QQ 邮箱：设置 → 账户 → 开启 POP3/SMTP → 生成授权码（不是登录密码）。

## 报告与历史

- `reports/YYYY-MM-DD.html`：完整中文报告（自包含，可直接双击打开），含组合占比、每只基金的建议与理由。
- `reports/YYYY-MM-DD.md`：Markdown 摘要。
- `reports/latest.json` / `latest.md`：最近一期，供面板和 DSH 提醒读取。
- `data/fundwatch.db`：运行记录、每日估值、信号历史（用于“连续 2 天确认”的滞后规则）。
- `logs/fundwatch.log`、`logs/dashboard.log`：运行日志。

## 信号规则（可解释、可回测）

1. **大盘评分**：上证、沪深300、创业板、科创50 的「站上 MA20 / MA20>MA60 / 20 日收益>0 / 5 日收益>0」四项打分取均值；沪深300 近 5 日跌超 3% 时最高只判「偏弱」。
2. **基金评分**：趋势 45 + 动量 20 + 回撤位置 20 + 相对强弱 15。
3. **趋势动作**：趋势强且大盘强 → 小幅加仓；趋势破位且回撤不深 → 减仓 10%；已深度回撤（>25%）且亏损 → 不在低位追杀，观望；RSI>75 或偏离 MA20>10% → 不追高/部分止盈；QDII 额外参考纳指期货。
4. **持仓比例修正**：单只超过 65% → 至少减回上限；加仓不超过「目标+5%」；低于「目标−5%」且评分≥55 → 小额定投式补仓；已低配的基金不再提示减仓。
5. **滞后规则**：动作切换需连续 2 个交易日出现，或评分变化 ≥15 分，避免来回打脸。
6. **费率护栏**：减仓时提示 C 类/A 类短持赎回费（7 天内通常 1.5%）。

## 数据源与容错

| 数据 | 主源 | 备源 |
|---|---|---|
| 指数实时 | 新浪 `hq.sinajs.cn` | 腾讯 `qt.gtimg.cn`、东财 push2 |
| 指数日线 | 腾讯 ifzq | 东财 push2his |
| 基金净值历史 | 天天基金 `pingzhongdata` | 东财 `FundMNHisNetList` |
| 盘中估值 | 腾讯 `jj` 估值字段 | 东财 `FundMNFInfo.GSZ`、指数/纳指代理 |
| 纳指/期货/汇率 | 新浪 | 缓存 + 降级标注 |

- 所有请求带 60 秒~6 小时缓存、按 host 限速、3 次退避重试；东财接口限流时自动降级并在报告里注明估值来源。
- 数据源都是公开免费接口，可能变更；报告里的「估值来源」会明确写出是实际净值、平台估值还是指数代理。

## 常见问题

**收不到企业微信/邮件？** 先运行 `run.py --test-push` 看返回；企业微信检查 webhook 是否被禁用、是否加了 IP 白名单；QQ 邮箱确认用的是授权码且已开启 SMTP。

**面板打不开？** 确认 8765 端口没有被别的程序占用；双击 `start_dashboard.bat`，或运行 `D:\python\python.exe dashboard.py --port 8765`。面板只监听本机，不要改成公网地址。

**修改持仓后建议没变？** 点击「刷新行情」重新计算；收益会立即按最新净值重算，但趋势建议需要最新行情。

**报告里的“当前市值”和 App 显示不一致？** 盘中估值是实时估算，且 QDII 净值滞后一天；以基金公司晚间公布净值为准。

**计划任务没跑？** `schtasks /Query /TN FundRadar_1430 /V /FO LIST` 查看“上次运行结果”；日志在 `logs/fundwatch.log`。如果移动了 Python，重新运行 `install_task.ps1`。

**只想看报告不推送？** `run.py --dry-run`（不推送、不写数据库）。
